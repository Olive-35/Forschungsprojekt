# Ordner

- `default_process/` – MQTT-Aufzeichnungen als JSON und JSONL sowie erzeugte Event-Logs im XES-Format.
- `event_log_creation/` – Skripte und Notebooks zur Aufbereitung der Aufzeichnungen und Erstellung von Event-Logs.
- `general_analysis/` – Werkzeuge und Notebook zur strukturellen Analyse der JSONL-Daten.
- `video_time_delay_comparison/` – Video, manuell gepflegte sichtbare Ereignisse und Notebook zum Zeitvergleich (muss noch fertiggestellt werden).
- `FT-MQTT-doc/` – Hintergrunddokumentation zum MQTT-Protokoll der Anlage.
- `Notizen/` – ergänzende Hinweise, unter anderem zu MQTT-Topics.
- `(Copy) FT-data-20260522/` – weitere aufgezeichnete Prozessdaten.
